# Changelog

All notable changes to this repository are recorded here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/). This is a sample deliverable, so
releases are revisions of the report rather than SemVer releases of an API.

## [Unreleased]

### Added

- Synthetic Harbor Goods exports: Cost and Usage Report extract, Compute Optimizer and Trusted Advisor
  results, and inventories, all generated by `scripts/generate_synthetic.py`.
- Offline audit scripts (`scripts/costaudit/`) for spend and trend, idle resources, rightsizing,
  Savings Plans and Reserved Instance coverage, tag coverage and the ranked savings list.
- `report/REPORT.md` rendered from a template and `report/REPORT.pdf` built from it.
- Tests that recompute every figure in the report from the data.
- ADRs, methodology, diagrams and a read-only `make test-live` smoke test.
- CI calls the shared `gamaware/.github` workflows pinned to a commit SHA, including the shared report
  evidence check.
- Social preview (`docs/assets/social-preview.png`) rendered with the shared generator.
