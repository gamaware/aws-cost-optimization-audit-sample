# CLAUDE.md

Project instructions for Claude Code. The global `~/.claude/CLAUDE.md` rules apply as well.

## Overview

A fictional sample deliverable: an offline AWS cost optimization audit of "Harbor Goods". Synthetic
exports in `data/synthetic/` feed Python scripts in `scripts/costaudit/`, which write `evidence/` and
render `report/REPORT.md` from `report/REPORT.template.md`. `scripts/build_pdf.py` turns the report
into `report/REPORT.pdf` with pandoc and Typst.

## Structure

- `data/synthetic/`: generated by `scripts/generate_synthetic.py`. Never edit by hand.
- `data/assumptions.json`: every unit price, threshold and effort/risk rating. Edit here.
- `scripts/costaudit/`: `model` (loading, money), `findings`, `commitments`, `analysis`, `report`.
- `report/REPORT.template.md`: prose only. Every figure is a `{{ placeholder }}`.
- `evidence/`, `report/REPORT.md`, `report/REPORT.pdf`: generated. Run `make evidence`.
- `tests/`: recompute every figure by hand arithmetic; fail on stale outputs.

## Commands

- `make verify`: lint, tests, and freshness of data, evidence, report and PDF. Offline.
- `make data`, `make evidence`, `make pdf`: regenerate outputs (`pdf` needs pandoc).
- `make test-live`: read-only exporter smoke test against the `dev` profile. Manual only; never in CI.

## Rules

- Money is `Decimal`; never float. Round per finding to cents; annual = 12 x monthly.
- Only AWS documentation example account IDs and RFC 5737 IPs. No real names, ARNs or emails.
- Label every saving as an estimate on fictional data. No AI mentions. English, dateless.
- Conventional commits on a feature branch; never commit to `main`.
- Claude hooks: `protect-generated.sh` blocks edits to generated files; `post-edit.sh` formats.
