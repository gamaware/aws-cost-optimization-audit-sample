# Security policy

This repository holds a fictional sample: synthetic billing data and offline scripts. It contains no
credentials and never calls AWS, except the manual, read-only `make test-live` target.

Report a vulnerability privately through
[GitHub security advisories](https://github.com/gamaware/aws-cost-optimization-audit-sample/security/advisories/new).
Do not open a public issue. The full policy is in the shared
[gamaware/.github](https://github.com/gamaware/.github/blob/main/SECURITY.md) repository.
